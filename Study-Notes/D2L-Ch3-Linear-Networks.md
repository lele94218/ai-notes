# 第三章：线性神经网络 (Linear Neural Networks)

## 3.1 线性回归 (Linear Regression)
- **模型定义**：假设输入与输出之间呈线性关系：$y = \mathbf{w}^\top \mathbf{x} + b$。
- **[[损失函数]] (Loss Function)**：衡量预测值与真实值的差距。
    - **[[均方误差]] (MSE)**：$\frac{1}{2}(y - \hat{y})^2$，线性回归最常用的损失函数。
- **优化算法**：
    - **[[解析解]]**：通过公式直接求出最优解（仅适用于简单线性模型）。
    - **[[随机梯度下降]] (SGD)**：深度学习的基石。每次随机采样一个[[小批量]] (Minibatch) 数据来更新参数，以降低计算成本。
- **训练流程**：初始化参数 -> 正向传播 -> 计算损失 -> 反向传播求梯度 -> SGD更新参数。

## 3.2 Softmax 回归 (Softmax Regression)
- **应用场景**：[[分类问题]] (Classification)，输出离散的类别。
- **[[One-Hot 编码]]**：将类别标签转换为向量（如 `[1, 0, 0]`）。
- **[[Softmax 函数]]**：
    - 将神经网络的输出（logits）转换为合法的**概率分布**（非负且和为 1）。
    - 公式：$\hat{y}_i = \frac{\exp(o_i)}{\sum_j \exp(o_j)}$
- **[[交叉熵损失]] (Cross-Entropy Loss)**：
    - 衡量两个概率分布之间的差异。
    - 在分类问题中，比均方误差更适合作为损失函数。

## 3.3 图像分类数据集 (Fashion-MNIST)
- 深度学习的“Hello World”数据集。
- 包含 10 个类别的服饰灰度图像 ($28 \times 28$)。
- 练习重点：数据读取 (`DataLoader`)、批量处理、可视化。
