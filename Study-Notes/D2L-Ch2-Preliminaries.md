# 第二章：预备知识 (Preliminaries)

## 2.1 数据操作 (Data Manipulation)
- **[[张量]] (Tensor)**：深度学习的基本数据结构，是标量、向量、矩阵的推广（N维数组）。
- **基本操作**：
    - **创建**：`torch.tensor`, `torch.zeros`, `torch.randn`。
    - **索引与切片**：`X[1:3]` (访问特定行)。
    - **[[广播机制]] (Broadcasting)**：当两个张量形状不同时，自动扩展维度进行运算（极为重要）。
- **内存管理**：
    - Python 的 `=` 赋值通常是引用。
    - 使用 `Y[:] = X + Y` 或 `torch.zeros_like(Y)` 来进行**原地操作**，节省内存开销。

## 2.2 线性代数 (Linear Algebra)
- **[[标量]] (Scalar)**：0阶张量（一个数）。
- **[[向量]] (Vector)**：1阶张量（一列数）。
- **[[矩阵]] (Matrix)**：2阶张量。
- **运算**：
    - **[[点积]] (Dot Product)**：向量元素相乘求和，衡量向量相似度。
    - **[[矩阵乘法]] (Matrix Multiplication)**：`torch.mm` 或 `@` 符号。
    - **[[范数]] (Norm)**：衡量向量的大小。
        - **$L_1$ 范数**：绝对值之和（稀疏性）。
        - **$L_2$ 范数**：平方和开根号（距离）。

## 2.3 微积分 (Calculus)
- **[[导数]] (Derivative)**：函数在某一点的瞬时变化率，是[[梯度下降]]的基础。
- **[[偏导数]]**：多元函数对某一个变量的导数。
- **[[梯度]] (Gradient)**：包含所有偏导数的向量，指向函数增长最快的方向。
- **[[链式法则]] (Chain Rule)**：复合函数求导法则，是[[反向传播]]算法的核心数学原理。

## 2.4 自动微分 (Automatic Differentiation)
- **[[自动微分]] (Autograd)**：深度学习框架的核心功能，自动计算计算图中所有参数的梯度。
- **[[计算图]] (Computational Graph)**：
    - **正向传播**：输入 -> 输出，同时构建计算图。
    - **反向传播**：`y.backward()`，从输出层向前计算梯度。
- **梯度累积**：PyTorch 默认会累积梯度，训练循环中必须手动清零 `grad.zero_()`。
